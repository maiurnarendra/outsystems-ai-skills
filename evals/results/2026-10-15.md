# Live test results: 2026-10-15

**Setup:** Claude Code with the skills loaded, connected to Service Studio (OutSystems 11) through the [OutSystems 11 MCP](https://github.com/OutSystems/outsystems11-mcp). Target: a real `_CS` module of a production application. Changes were generated, read back from the model, validated by TrueChange, then reviewed by a developer in the Compare-and-Merge window. Both merges were cancelled afterwards because these were test runs.

These are **with-skill** runs only. No baseline (without-skill) comparison was run yet.

## Test 2: entity, CRUD wrappers and bulk delete

**Prompt:** create an entity `TestingNewEntityAI` (Name text 200, IsNew, DatetimeOfBirth, log fields), its CRUD actions, and an Advanced SQL action that deletes all records in bulk.

| Check | Result |
|---|---|
| Entity name CamelCase, singular; attribute `DatetimeOfBirth` corrected to `DateTimeOfBirth` | ✅ |
| Public = Yes, Expose Read Only = Yes; `CreatedBy` / `UpdatedBy` typed as User identifiers | ✅ |
| `TestingNewEntityAI_CreateOrUpdate`: input `Source`, output `Id` | ✅ |
| Branches on `Source.Id <> NullIdentifier()`, If labelled `IsExistingRecord` | ✅ |
| True (update) down, False (create) right, straight non-crossing connectors | ✅ |
| Create sets all four log fields; update keeps created values and sets updated values | ✅ |
| `TestingNewEntityAI_Delete`: input `Id` | ✅ |
| Bulk delete in one Advanced SQL node with header comment and tab indentation | ✅ |
| Descriptions on actions, inputs, outputs and attributes | ✅ |
| Developer review in Service Studio | ✅ "CRUD correctly created, delete too; the advanced query was simple but commented and well structured" |

**Findings:**
1. First attempt wrote `GetTestingNewEntityAIForUpdate.Record.CreatedOn`. TrueChange reported it and the agent corrected it to `Record.TestingNewEntityAI.CreatedOn`. The skill now documents the path (v0.5.0).
2. The bulk delete is not one of the two documented wrappers, but the module already used `<Entity>_DeleteAll` widely. The skill now allows `<Entity>_DeleteAll` as an optional bulk delete in Advanced SQL (v0.5.0); eval `crud-05` covers it.
3. Source validation was skipped because no validation exception existed. Not a skill change.
